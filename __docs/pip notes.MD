## shows packages in a readable table format
```sh
pip list 
```

### To list details for a specific package using pip, run this command in your terminal:
```sh
pip show <package-name>
```

## shows them in a format suitable for requirements.txt files.
```sh
pip freeze 
```

## Install packages from requirements.txt file
```sh
pip install -r requirements.txt
```

## Install packages and upgrade if already installed
```sh
pip install -r requirements.txt --upgrade
```

## update pip install
```sh
python.exe -m pip install --upgrade pip
```
